# Custom Data Import Wizard

A Salesforce LWC mini-project built while learning LWC and Apex.

This component allows users to upload a CSV file, select a Salesforce object, map CSV columns to Salesforce fields, and import records into Salesforce.

## Features

- Upload CSV files
- Dynamically select Salesforce objects
- Fetch object fields dynamically
- Map CSV columns to Salesforce fields
- Import multiple records
- Success and error handling

## Tech Used

- Lightning Web Components (LWC)
- Apex
- Salesforce Schema Describe
- JavaScript FileReader
- Dynamic SObjects
- Bulk DML

## How It Works

Upload CSV → Select Object → Map Fields → Import Records

## Purpose

Built as a hands-on LWC learning project to practice LWC-Apex communication, dynamic metadata, file handling, and bulk record processing.

> This is a standalone LWC mini-project and is separate from my main Salesforce portfolio project.
